### 3D ER & Mitochondria Segmentation Refinement

*Team project · Machine Learning & Computer Vision*

Contributed to a team pipeline for refining organelle segmentation in **3D electron microscopy** volumes.

- Focused on **voxel classification** and conservative refinement of endoplasmic reticulum (ER) labels.
- Explored **graph-cut post-processing** under explicit label constraints.
- Developed evaluation and visualization workflows to compare predictions and check that protected labels remain unchanged.

**Tools & methods:** `Python` `NumPy` `Graph cuts` `HPC`

### AI-Powered Quiz & Assessment Platform

*Undergraduate thesis project · Full-stack development*

Designed and implemented an application for creating quizzes, collecting answers, and evaluating results.

- Built a **Spring Boot** backend and **Vue 3** interface, with **MySQL** and **Redis**.
- Integrated **ChatGLM** for AI-assisted question generation and scoring, using **RxJava + Server-Sent Events** for streaming responses.
- Implemented question management, answer history, application review, role-based access, and usage statistics.

**Stack:** `Java` `Spring Boot` `Vue 3` `MySQL` `Redis` `RxJava` `SSE`
